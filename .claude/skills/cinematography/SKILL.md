# ショット構成 & ライティング理論

# PART A: ショット構成

## A-1. ショットサイズの語彙(7段階)

| サイズ | 記号 | 伝わるもの | MVでの主用途 |
|---|---|---|---|
| 超ロング | ELS | 世界の中の点としての人 | イントロ・孤独の提示 |
| ロング | LS | 人と環境の関係 | 状況説明・ダンス全身 |
| フル | FS | 全身の所作 | 振付・歩き |
| ミディアム | MS | 会話距離。基準ショット | Aメロの標準 |
| バストアップ | MCU | 感情が読める距離 | Bメロ・歌唱 |
| クローズアップ | CU | 感情そのもの | サビ・決定的瞬間 |
| 超クローズ | ECU | 目・唇・指先。無意識 | フック直前・親密の極点 |

**設計原則: サイズの遷移は感情の遷移。** Aメロ MS→Bメロ MCU→サビ CU と寄っていくのが基本文法。あえて逆走(サビで超ロング)すると「感情の放流」になる — 広い空へ感情を解き放つラスサビ等。

## A-2. 構図の法則(2.5Dレイアウトでそのまま使う)

1. **三分割法** — 主役は交点に。歌詞は下1/3線上に。中央配置は「ここぞ」の対称演出専用。
2. **リードルーム** — 移動・視線方向に余白を取る。詰めると閉塞感(意図的に使うのは可)。
3. **ヘッドルーム** — 頭上余白。切りすぎ=圧迫、空けすぎ=孤独。感情で決める。
4. **リーディングライン** — 道路・電線・光条で視線を主役へ導く。パララックス層の設計時に線の収束点を決めておく。
5. **フレーム内フレーム** — 窓・ドア・鏡で二重に切り取る。「閉じ込め」「覗き」の記号。KNJYKKI頻出。
6. **対称構図** — 中心対称は神聖・静寂・狂気。ここぞの1カットだけ。ウェス・アンダーソン化に注意。
7. **対角構図** — 動きと不安。静的な素材を動的に見せる安価で強力な手段(全体を-6°回転)。
8. **ネガティブスペース** — 画面の70%を空けて小さな主役。孤独と余韻。歌詞を余白側に置ける実利もある。
9. **黄金比スパイラル** — 三分割より有機的な配置。ジャケット的1枚絵カットに。
10. **地平線の高さ** — 低い地平線=空・自由・未来 / 高い地平線=地面・重さ・現実。セクションごとに使い分ける。

## A-3. カット割り設計

- **180度ルール** — 2者の位置関係軸を跨いで切り返さない(跨ぐなら移動ショットを挟む)。2.5DのMVでも左右関係の一貫性として適用。
- **30度ルール** — 同一被写体のカット間はアングル30度以上 or サイズ2段変える。微差カットはジャンプカットに見える(§意図的なら可)。
- **アクションつなぎ** — 動作の中間で切る。完結後に切ると死ぬ。
- **モンタージュの文法** — クレショフ効果: カットAの意味はカットBが決める。「無表情+雨」=悲しみ、「無表情+花」=希望。歌詞と絵の組合せにもそのまま働く。**歌詞と完全同義の絵を並べない**(冗長)。半歩ずらすと詩になる。
- **カット尺の音楽量子化** — `transitions` スキル冒頭参照。基準: Aメロ2小節/カット、Bメロ1小節、サビ0.5〜1小節。
- **ショットリストの型** — 各セクションを「エスタブリッシュ(状況)→ミディアム(人物)→インサート(細部)」の3点セットで構成すると破綻しない。

# PART B: ライティング理論

## B-1. 三点照明とその崩し方

- **キーライト** — 主光源。方向が感情を決める(下記B-2)。
- **フィル** — 影を起こす補助光。キーとの比=**ライティングレシオ**。1:2=標準、1:8=ドラマチック(ノワール)、1:1=フラット(アイドル・広告)。KNJYKKIは1:4〜1:8を基準とする。
- **バックライト(リム)** — 輪郭光。被写体を背景から剥がす。夜シーンの生命線。

崩し方: MVでは「三点そろえる」より**動機付け照明(motivated lighting)** — 画面内に光源の言い訳(ネオン・窓・スマホ・自販機)を置き、その色と方向で照らす。KNJYKKIの世界は常に「どこかの実在の光」で照らされていること。

## B-2. 光の方向の意味

| 方向 | 効果 |
|---|---|
| 順光 | 情報的・フラット。感情が薄まる(意図的な「日常」に) |
| サイド光 | 立体・葛藤。顔の半分が闇=二面性 |
| 逆光 | シルエット・神聖・匿名。エモの王道 |
| 下から | 不穏・恐怖(懐中電灯怪談) |
| 真上から | 尋問・孤立(裸電球の取調室) |
| 画面外から | 「見えない何か」の存在。想像の余白 |

## B-3. ハイキー / ローキー

- **ローキー**(暗部支配・高コントラスト) — KNJYKKI標準。闇の中の少ない光。
- **ハイキー**(明部支配・低コントラスト) — 回想・夢・喪失の白。ローキーの曲中に1シーンだけ置くと強烈な異物感が出る。

## B-4. 色温度の物語

電球色(2700K/Amber)=記憶・室内・ぬくもり ←→ 昼光色〜モニタ光(6500K+/Cyan)=現実・孤独・デジタル。
**1画面に2色温度を同居**させる(窓外は青い夜+室内は橙の電球)のが最も「映画」に見える構図。KNJYKKIパレットの Rose/Cyan/Amber はこの理論の様式化である。

## B-5. Remotionでの光の実装レシピ

光は全て「レイヤー+ブレンドモード」で作る。実装順: 環境光→動機光源→リム→大気→フリッカー。

```tsx
// 1. スポット/動機光源: radial-gradient + screen
<AbsoluteFill style={{background:
  `radial-gradient(600px 800px at 70% 20%, ${palette.dawnAmber}55, transparent 70%)`,
  mixBlendMode: 'screen'}} />

// 2. ゴッドレイ(光条): conic-gradientの扇を光源から。低opacityで2枚ずらし重ね
<AbsoluteFill style={{background:
  `conic-gradient(from 160deg at 70% 10%, transparent 0deg, #F5F3F022 8deg,
   transparent 16deg, #F5F3F011 24deg, transparent 40deg)`,
  mixBlendMode: 'screen', opacity: 0.6}} />

// 3. ブルーム(発光体のにじみ): 光る要素を複製してblur
<div style={{position: 'absolute', filter: 'blur(24px)', opacity: 0.7}}>{neonSign}</div>
<div style={{position: 'absolute'}}>{neonSign}</div>

// 4. 大気(ヘイズ): 奥のレイヤーほど背景色を薄く被せる = 空気遠近法
<AbsoluteFill style={{background: palette.midnight, opacity: depth * 0.35}} />

// 5. フリッカー(蛍光灯・ネオンの明滅): 決定論的ランダム
const flicker = random(`fl-${Math.floor(frame / 3)}`) > 0.92 ? 0.6 : 1; // 3fごとに8%の確率で暗落ち
<AbsoluteFill style={{opacity: flicker}}>{lightLayer}</AbsoluteFill>

// 6. 影の実装: 光源と逆方向にskewした半透明黒 + blur
<div style={{transform: 'skewX(-30deg) scaleY(0.4)', transformOrigin: 'bottom',
  filter: 'blur(6px)', background: '#0B0E1A', opacity: 0.5}} />
```

### 光の演出タイミング
- 光源の点灯は音に同期させる(スイッチ音・キック)。**音のない点灯は事故に見える**。
- リムライトはサビで強める(輪郭発光=存在の強度)。
- フリッカーはAメロ・ブリッジ限定。サビでは光を安定させる(chorus-impact §17)。

## B-6. チェックリスト

- [ ] 1画面に2色温度が同居しているか(単色照明は意図がある時だけ)
- [ ] 被写体と背景がリム or 明度差で分離できているか
- [ ] 影の方向が光源と矛盾していないか(レイヤー使い回し時の事故多発点)
