# トランジション 120種類

## 共通実装イディオム: TransitionShell

2シーンを重ね、進行率 `p`(0→1)で out側/in側 のスタイルを制御する。

```tsx
// scene-library/components/TransitionShell.tsx の骨格
type TStyle = (p: number) => {out: CSSProperties; in: CSSProperties};
const p = interpolate(frame - startFrame, [0, durFrames], [0, 1],
  {extrapolateLeft: 'clamp', extrapolateRight: 'clamp',
   easing: Easing.inOut(Easing.cubic)});
<AbsoluteFill style={styles.out}>{sceneA}</AbsoluteFill>
<AbsoluteFill style={styles.in}>{sceneB}</AbsoluteFill>
```

以下、各項目は **名前 — 意味/使いどころ。実装キー**(`out:`/`in:` のスタイル式)。
`@remotion/transitions` の `fade/slide/wipe/flip/clockWipe` で済むものはそれを使う。

### トランジションの意味論(選定の大原則)

- **カット** = 同一時間内の視点変更。**ディゾルブ** = 時間経過・記憶。**ワイプ** = 場所の移動。
- **白フェード** = 感情の飽和/死/回想入り。**黒フェード** = 章の終わり/眠り。
- **グリッチ** = 通信/精神の断絶。**ズーム/モーション** = 勢いの持続。
- 尺の基準: ビート同期(0.5拍/1拍/2拍)に量子化する。中途半端な尺が一番ダサい。

## §1 カット系 (1–10)

1. **ストレートカット** — 全トランジションの王。拍頭に置く。実装: 単なるSequence切替。
2. **ジャンプカット** — 同構図で時間だけ飛ぶ。焦燥・省略。数フレーム間引いた同シーン連結。
3. **カットイン(寄り)** — 同一被写体へ2段階寄る。緊張の階段。
4. **カットアウェイ** — 一瞬別のモチーフ(時計・空)を挟んで戻る。心情の注釈。
5. **スマッシュカット** — 静→轟(またはその逆)へ落差最大で切る。サビ頭/サビ明け。
6. **Jカット** — 次シーンの音が先に来る(音のSequenceを先行開始)。自然な誘導。
7. **Lカット** — 前シーンの音が残る。余韻・引きずり。
8. **インビジブルカット** — 暗部/前景横切りで切れ目を隠す(黒レイヤーが画面を覆う瞬間に切替)。
9. **フラッシュカット** — 2フレーム白(or 別画)を挟んで切る。記憶のフラッシュバック。
10. **ビートカット連打** — 8分音符ごとの高速カット群。ビルドアップ末尾専用。

## §2 フェード/ディゾルブ系 (11–22)

11. **クロスディゾルブ** — `out.opacity: 1-p / in.opacity: p`。時間経過の基準形。
12. **黒フェード(F.O.→F.I.)** — 一度黒を経由。章区切り。黒保持は1拍まで。
13. **白フェード** — 白経由。感情の飽和。サビ明けの放心に。
14. **ディップトゥカラー** — ブランド色(Neon Rose等)を経由。KNJYKKIの署名的つなぎ。
15. **加算ディゾルブ** — in側を `mix-blend-mode: screen` で重ねてから通常合成へ。光として到来する。
16. **スマートディゾルブ** — 同構図・同ポジの2画をディゾルブ(時間経過モンタージュ§72用)。
17. **ブラーディゾルブ** — 両者にblurを山なりに掛けつつ交差。夢と現の境界。
18. **粒状ディゾルブ** — turbulence displacementを山なりに掛け、砂嵐を経由して替わる。
19. **露出ディゾルブ** — out側を白飛びさせながらin側を浮かせる。`filter: brightness(1→3)`。
20. **焦点ディゾルブ** — out側がボケきった所でin側がピントを結ぶ。ラックフォーカスの2シーン版。
21. **多重露光保持** — 交差の中間(両方50%)を意図的に2小節保持する。共存・すれ違いの表現。
22. **フェードスルーグレイン** — グレイン量を一時的に10倍へ→戻すと画が替わっている。フィルム的。

## §3 ワイプ系 (23–37)

23. **リニアワイプ(左→右)** — 場所の移動。`in.clipPath: inset(0 ${(1-p)*100}% 0 0)`。
24. **リニアワイプ(右→左)** — 帰還・回想方向。
25. **バーティカルワイプ(下→上)** — 上昇・希望へ。
26. **バーティカルワイプ(上→下)** — 幕引き・沈降。
27. **対角ワイプ** — 勢い重視。`clip-path: polygon` を対角に走らせる。
28. **ソフトエッジワイプ** — 境界にグラデ帯。`mask-image: linear-gradient` の位置を動かす。上品。
29. **クロックワイプ** — 時計回りに開く。時間モチーフ。`@remotion/transitions/clockWipe`。
30. **アイリスイン/アウト** — 円形に開閉。`clip-path: circle(r% at x y)`。注目点の指定。レトロ。
31. **バーンドアワイプ** — 中央から左右へ観音開き。開演の記号。
32. **ブラインドワイプ** — 複数の横帯が順に開く。inset複数本をstagger。
33. **チェッカーワイプ** — 市松のタイルが順に反転。conic/gridで16分割し遅延反転。
34. **ジグザグワイプ** — 稲妻形polygonが走る。エネルギッシュ。
35. **波形ワイプ** — 境界線がsin波でうねりながら進む。水モチーフ。SVG maskで。
36. **文字型ワイプ** — 歌詞の文字形に `clip-path` して次シーンが文字の中から広がる。
37. **ロゴワイプ** — KNJYKKIロゴのシルエットが拡大して全画面を飲み込む。決めの1回のみ。

## §4 スライド/プッシュ系 (38–47)

38. **プッシュ(左)** — in側がout側を押し出す。`out.x: 0→-W / in.x: W→0`。場面の並列関係。
39. **プッシュ(右/上/下)** — 方向で意味付け(上=進展、下=後退)。
40. **スライドオーバー** — in側が上に被さる(out側は動かない)。上書きされる記憶。
41. **スライドアウェイ** — out側が退場してin側が現れる(in側は最初から下に)。幕が剥がれる。
42. **スプリットスライド** — out側が上下2枚に割れて逃げる。`clip-path` 上半分/下半分を逆方向へ。
43. **カーテンスライド** — 左右2枚に割れて逃げる。開幕。
44. **段組スライド** — 画面を4帯に割り、時間差で同方向スライド。リズミカル。
45. **弾性プッシュ** — springs.snapでオーバーシュートするプッシュ。ポップ寄り(KNJYKKIでは控えめに)。
46. **慣性スライド+ブラー** — 速度に比例した `blur(px)` を乗せる。高級感の要。
47. **紙芝居抜き** — out側が手前に滑り落ちて捨てられる(`y: +H, rotate: 6°`)。アナログ感。

## §5 ズーム/モーション系 (48–59)

48. **ズームイン突入** — out側の一点へ `scale: 1→8` + blur、その点からin側が開く。窓・目・光源に飛び込む。
49. **ズームアウト着地** — in側が `scale: 8→1` で引いて到着。
50. **無限ズーム(ドロステ)** — in側をout側の画中画に仕込み、ズームで入れ子を通過。強烈な没入。
51. **ホイップパン・トランジション** — 高速パン+blurで振り切り、blur中に差し替える。定番中の定番。
52. **ホイップティルト** — 縦振り版。落下・見上げの文脈で。
53. **ロールスピン** — `rotate: 0→180°`+blur中に切替、`180→360°`で復帰。DJスピン感。
54. **バウンスズーム** — ズームで寄る→跳ね返って別シーン。遊び心。
55. **速度ランプつなぎ** — out側を徐々にスロー→静止した瞬間に切る。余韻→転換。
56. **モーションマッチ** — out側の移動方向・速度をin側が引き継ぐ(右パン→右パン)。無縫の流れ。
57. **落下つなぎ** — カメラが落下(y加速)→着地の衝撃フレームで次シーン。
58. **ドリーバックリビール** — 引いたらそこは別の場所だった(額縁・スクリーンの中から出る)。
59. **視線モーション** — キャラの視線移動方向にホイップして次シーンへ。視線=編集点。

## §6 回転/フリップ系 (60–66)

60. **カードフリップ** — `rotateY: 0→90°`で切替、`90→0°`。表裏の関係にある2シーン。
61. **キューブ回転** — 2面を90°配置して箱ごと回す。`@remotion/transitions/flip` 拡張。
62. **風車回転** — 中心からの4枚羽根が回って画面を置換。レトロポップ。
63. **ページカール風** — 角からめくれる(グラデ影+skewで近似)。日記・手紙モチーフ。
64. **万華鏡回転** — 画面を扇形ミラー分割して回し、収束すると次シーン。サイケ・間奏。
65. **天地回転** — `rotate: 180°`して次シーンは逆さの世界(mv-direction §61へ)。
66. **時計盤回転** — 画面全体が時計の針として回り、通過跡が次シーン。時間経過の明示。

## §7 マスク/シェイプ系 (67–81)

67. **サークルバースト** — 中央から円が拡大して全画面へ。`circle(0%→150%)`。ポップな開放。
68. **マルチサークル** — 複数の円がランダム位置から時間差で開く。泡・雨滴。
69. **ダイヤ/スターワイプ** — 図形型polygonの拡大。様式美・レトロ。
70. **ハニカム展開** — 六角形タイルが順に反転。テック系。
71. **ストライプ収束** — 細い縦帯が中央へ集まり画面を閉じる→開くと次。
72. **シルエット通過** — 歩く人物の黒シルエットが横切り、通過跡が次シーン。物語的で美しい。
73. **前景オブジェクトマスク** — 電柱・柱が画面を横切る瞬間に切替(インビジブル§8の明示版)。
74. **ドアフレーム通過** — ドア/改札/エレベーターを通ると次の世界。空間の文法。
75. **手のひらクローズ** — 手が画面を覆う→開くと次。主観的・私的な転換。
76. **インクブロット** — 墨が滲み広がるマスク。turbulence+thresholdで有機的な縁を作る。
77. **稲妻フラッシュマスク** — 稲妻形が2フレーム光り、雷鳴とともに次シーン。
78. **紙破りマスク** — ギザギザpolygonが裂けて広がる。衝動・破壊。
79. **液体流し込み** — 上から液体が流れ落ちて画面を満たす。satisfying系。
80. **視界瞬きマスク** — 上下瞼が閉じて開く。主観の時間経過(気絶・寝落ち・涙)。
81. **鍵穴/スコープ** — 鍵穴形に締まってから次へ。覗く/覗かれるの文脈。

## §8 グリッチ/デジタル系 (82–93)

82. **RGBスプリット切替** — 3チャンネルが別方向に割れて再結合すると次シーン。
83. **ブロックノイズ崩壊** — 矩形ノイズが増殖して画面を覆い、晴れると次。データモッシュ的。
84. **スキャンライン置換** — 走査線が上から下へ通過し、通過済み行だけ次シーン(横帯clipの束)。
85. **信号ロスト** — 「NO SIGNAL」/カラーバーを1拍挟む。断絶・章替わり。
86. **ピクセレート経由** — mosaic化(縮小→拡大レンダ)が極大化→戻ると次シーン。
87. **VHS巻き戻し** — 巻き戻しノイズ+高速逆再生風の残像→停止すると次(回想入りの定番)。
88. **データワイプ** — 0/1やコード文字列の奔流が画面を洗う。
89. **フレームドロップ切替** — カクカクとフレームを飛ばしながら次シーンが混ざり込む。
90. **デッドピクセル増殖** — 黒点が増えて全滅→反転して次。
91. **走査線ロール** — 画面全体が垂直ロール(古TVの同期ズレ)して安定すると次。
92. **グリッチワード** — 歌詞が文字化け(lyrics-animation §89)しつつ画面ごと切替。
93. **シャッターチルト** — ローリングシャッター風に画面が斜めに歪んで切替。

## §9 光/露出系 (94–103)

94. **レンズフレアワイプ** — フレアが横切る光量ピークで切替。王道エモ。
95. **ライトリーク** — 画面端から漏れ光(オレンジのグラデ)が侵食して次へ。フィルム的。
96. **ブルームアウト** — 全光源のブルームが肥大化して画面が白に溶ける。§13の光源版。
97. **フリッカーカット** — 蛍光灯の明滅の暗の瞬間に切り替わっている。ホラー/緊張。
98. **シルエット化つなぎ** — 逆光が強まり真っ黒シルエットだけになった所で背景ごと差し替え。美しい。
99. **プロジェクター起動** — 映写機の光芒+ダスト→スクリーンに次シーンが投影される。
100. **露出オーバー→回復** — 白飛び→絞りが戻ると別の場所。目が慣れる感覚。
101. **ネオン明滅つなぎ** — ネオンが2回明滅、3回目の点灯で世界が替わる。KNJYKKI署名。
102. **光の柱通過** — 縦の光帯が横切り、通過跡が次シーン(§84の光版)。
103. **日没タイムラプス** — 照明色だけが数秒で夜に変わり、暗転明けに次シーン。

## §10 3D/空間系 (104–110)

104. **Z通過つなぎ** — 前景レイヤーがカメラを通過する瞬間に世界を差し替え(camera-work §19)。
105. **壁抜け** — 壁に向かってドリー→突き抜けた先が次の部屋。間取りの連続性が生む快感。
106. **床落下** — 床が消えて落下、着地先が次シーン。
107. **折り紙フォールド** — 画面が2〜3枚に折り畳まれて裏面が次シーン。
108. **ビル倒立回転** — 都市レイヤーが90°倒れて新しい地面になる(インセプション風)。
109. **パララックス反転** — 奥行きが裏返る(背景が前景に)。世界観の反転そのもの。
110. **ミニチュア引き** — 引いたら今のシーンはジオラマ/スノードームだった(mv-direction §57と接続)。

## §11 マッチカット系 (111–115) — 最高級のつなぎ。絵コンテ段階で仕込む

111. **形状マッチ** — 満月→時計→瞳、円は円へ。同座標・同サイズで切る。
112. **動作マッチ** — 振り向き→別シーンで振り向き終わる。動作の中間で切る。
113. **色マッチ** — out側の支配色が次シーンの1点に受け継がれる。
114. **音マッチ** — ドアの閉音=キックに重ねて切替。音が編集点を「正当化」する。
115. **構図マッチ** — 同一構図で場所だけ変える(mv-direction §72タイムラプスの1カット版)。

## §12 素材系 (116–120)

116. **煙幕通過** — 煙が画面を覆い、晴れると次。turbulence雲レイヤーを横断させる。
117. **雨幕強調** — 雨脚が一瞬強まり白レイヤー化→弱まると次シーン。
118. **花吹雪/紙吹雪** — パーティクル密度を一時的に画面占有率100%へ。祝祭・春。
119. **鳥/群れの横断** — 黒い群体が画面を横切る。時間と距離の飛躍。
120. **水没・浮上** — 画面が水に沈む(青転+波紋+blur)→浮上すると次の世界。
