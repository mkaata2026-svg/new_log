# エモさを生む映像心理学

「エモい」は偶然ではなく設計できる。本スキルは感情反応の心理的メカニズムと、それをMV構成に落とす方法をまとめる。

## 1. 緊張と解放 (Tension & Release) — すべての土台

感情の強度は刺激の絶対量ではなく**期待からの差分**で決まる。

- **貯める→裏切る→解放する**。ビルドアップ(貯め)→無音の1拍(裏切り)→サビ(解放)が最強の3段構造である理由。
- 解放の快感は貯めた時間に比例する。camera-work §50(1コーラス固定→ラスサビ解禁)、color-design の「Amber封印」、chorus-impact §45(落ちサビ)はすべてこの原理の応用。
- **一度使った解放は二度目から効かない**。1番サビと同じ手をラスサビで使うなら、必ず1軸追加する(chorus-impact §5)。

### 期待の作り方(予告のテクニック)
- 反復による学習: 同じ演出を2回見せると視聴者は3回目を予測する。3回目で裏切る(2回の法則)。
- 視覚的予告: サビで爆発する光源を、Aメロで小さく点滅させておく。「銃はあらかじめ壁に掛けておく」。
- 上昇の記号: ティルトアップ・音程上昇・明度上昇はすべて「これから何かが起こる」の合図。同時に使うと期待は乗算される。

## 2. フリソン(鳥肌・チルズ)の条件

音楽心理学でフリソンが起きやすいのは: **予想外の和声変化 / 急激な音量変化 / 声の裏返り・ブレイク / 新しい声部の参加**の瞬間。映像側はこれを増幅できる:

| 音楽側のトリガー | 映像側の増幅装置 |
|---|---|
| 転調 | 画面全体のリフト(mv-direction §94)・世界の着彩 |
| ブレイク(全楽器停止) | 完全静止・暗転(mv-direction §40) |
| コーラス隊の参加 | 群衆・多重露光・窓の多重(mv-direction §68) |
| オクターブ上のロングトーン | ティルトアップ+ブルーム肥大+粒子上昇 |
| 最後のサビ前の静寂 | 10フレームの黒 or 白。**映像が音より0.5拍早く静まる**と鳥肌が増す |

**同期のミクロ精度が効果を左右する**。フリソン狙いのカットは±1フレームで音に合わせること。

## 3. ノスタルジー設計

ノスタルジーは「個人の記憶」ではなく**「記憶の様式」**への反応。実体験がなくても効く。

- **メディアの劣化=時間の経過**: VHSノイズ・フィルムグレイン・色褪せ(彩度低下+Amberキャスト)・4:3画角・日付スタンプ。劣化表現は「これは過去だ」という文法として通じる。
- **黄昏効果**: 夕暮れの光(斜光+長い影+Amber)は生物学的に「終わり」を予感させる。1日の終わり=時代の終わり=関係の終わりの重ね合わせ。
- **具体的な生活小物**: 抽象より具象が刺さる。改札・自販機の光・コンビニ袋・扇風機・カーテンの揺れ。「誰の記憶でもある風景」を選ぶ。
- **距離化**: 記憶は常に少し遠い。回想シーンは寄りより引き、直接光より窓越し・すりガラス越し。
- 注意: ノスタルジー装置は3種まで。盛りすぎると「レトロ風広告」になり感情が死ぬ。

## 4. 感情曲線の設計(1曲=1つの物語)

MV全体の感情強度をグラフに描いてから作る。基本形:

```
強度
 9 |                                    ラスサビ★
 7 |            サビ1        サビ2     /
 5 |           /    \       /   \    / 
 3 |  イントロ /      間奏  /     \  /←落ちサビ(2まで落とす)
 1 | ___/  Aメロ         Aメロ2   ブリッジ
   +----------------------------------------→ 時間
```

- **単調増加は失敗**。強度5→9より、2→9の方が9が高く感じる(対比の原理)。ブリッジ/落ちサビの「谷」は削ってはいけない演出資源。
- **開始30秒の掴み**と**最後の余韻**は曲線の外にある独立タスク(mv-direction §1, §100)。
- 各セクションの強度を1〜10で先に数値化し、7軸パラメータ(chorus-impact冒頭)の配分をそれに従わせる。

## 5. 速度とイージングの心理

- **加速=意志、減速=感慨、等速=機械**。同じ移動でもイージングで感情が変わる。
- **スローモーション**は「この瞬間は重要だ」の宣言。乱用すると全部が重要=何も重要でなくなる。1曲2回まで。
- **速度ランプ**(通常→急スロー): 決定的瞬間の直前で時間が伸びる主観の再現。落下・すれ違い・目が合う瞬間。
- 人間は**0.3〜0.5秒**の動きを「所作」として最も美しく感じる(能・茶道の間)。UIアニメの0.2秒より遅く、日常動作より遅く。KNJYKKIの標準トランジション尺=1拍がこの帯域に入るテンポ(120-180BPM)を優遇する理由。
- **予備動作(anticipation)**: 大きく動く前に小さく逆へ。ジャンプ前のしゃがみ。サビ前に画面がわずかに「沈む」(y+8px, 2フレーム)とサビの跳躍が伸びる。

## 6. 不完全性の美学(なぜ完璧な画面はエモくないか)

- 完璧な整列・完全な静止・ノイズゼロの画面は「無人」に感じる。**人の痕跡=わずかな乱れ**。
- KNJYKKI標準の グレイン+微手ブレ+ネオンの明滅 は「世界が生きている」ためのバイタルサイン。
- **ズレの美学**: 完全同期の中に1つだけ半拍ズレたものを置く(全窓が同時に灯る中、1つだけ遅れて灯る)。視聴者はズレたものに感情移入する。
- 手描き・手書き文字の混入は最強の「人の痕跡」。1本に1箇所、機械的な画面に手書きを置く。

## 7. 視線と余白の心理

- 視聴者の視線は 光る物→動く物→顔→文字 の優先順で吸われる。**歌詞を読ませたい行の瞬間は、光と動きを抑える**(全部主張する画面は何も読まれない)。
- **余白は感情の置き場**。ネガティブスペース(cinematography A-2-8)は視聴者が自分の感情を投影するために空けておく領域。情報で埋めるほど視聴者の感情の入り込む隙間が減る。
- **顔を見せない力**(mv-direction §79): 顔が見えないと視聴者は自分を代入する。共感の最大化。ここぞで初めて顔を見せると、それは「出会い」になる。

## 8. 反復と変奏(音楽的構造の視覚化)

- 曲のリフレインに対し映像もリフレインを作る(同構図の再登場)。**2回目の同構図は1回目と「意味が変わって」見える**(文脈が更新されているため)。これが円環構造(mv-direction §82)の効く理由。
- サビごとに同じ演出を「成長」させる: 1番=芽、2番=蕾、ラスサビ=開花。同一性が担保する物語性。
