# 歌詞アニメーション 80パターン

## 共通実装イディオム

全パターンの土台。**行→単語→文字**の3階層で分解し、文字ごとに遅延を与える。

```tsx
// scene-library/components/LyricLine.tsx の骨格
const chars = line.words.flatMap((w) => [...w.text].map((c) => ({c, startSec: w.startSec})));
{chars.map((ch, i) => {
  const local = frame - ch.startSec * fps - i * stagger; // stagger: 文字遅延(1〜3f)
  const p = spring({frame: local, fps, config: springs.knj});
  return <span key={i} style={styleFor(p, i)}>{ch.c}</span>;
})}
```

- `p` は 0→1 の進行率。以下の各パターンは `styleFor(p, i)` の中身。
- 消滅系は `pOut = 1 - spring({frame: frame - line.endSec * fps, ...})` を掛け合わせる。
- **KNJYKKI標準**: stagger 2f / springs.knj / 出現・消滅は必ず対で設計する。

## §1 出現系 (1–24)

1. **フェードイン** — `opacity: p`。迷ったらこれ。上品の基準線。
2. **フェード+ライズ** — `opacity: p; translateY: (1-p)*20px`。標準その2。
3. **フェード+沈み込み** — 上から降りてくる版。落ち着き・諦観。
4. **ブラー解像** — `filter: blur((1-p)*12px)`。記憶が像を結ぶ。バラードに最適。
5. **タイプライター** — 文字を `local >= 0` で瞬時表示+カーソル点滅。機械・独白。
6. **カラオケワイプ** — 行を二重描画し、上層を `clip-path: inset(0 ${(1-p)*100}% 0 0)` で発音進行に同期して開く。
7. **単語ポップ** — 単語単位で `scale: 0.8→1` spring。リズミカルな曲。
8. **文字バラ落ち** — 上から `translateY: -(1-p)*80px` + 微回転、文字ごとランダム遅延。
9. **滲みインク** — blur+`opacity` を重ね、にじみが収束。和風・情緒。
10. **走査線出現** — 行の上を光る線が通過し、通過済みだけ表示。デジタル。
11. **グリッチ出現** — 表示直前3フレームだけ `translateX: ±4px` + RGBずれ→定位置。
12. **点滅出現** — 2回明滅してから点灯。ネオン管の点き方。`opacity: [0,1,0,1,0.3,1]` をフレーム段階で。
13. **拡大衝突** — `scale: 3→1` + `opacity: 0→1` を8フレームで。サビの1行目。
14. **奥からドリー** — `scale: 0.2→1` + blur解像。遠くから届く言葉。
15. **スライドマスク** — `overflow: hidden` の行ボックス内で `translateY: 100%→0`。切れ味のある上品さ。
16. **回転ヒンジ** — `rotateX: -90°→0`(transform-origin: bottom)。パタッと起き上がる。
17. **手書きストローク** — SVG `stroke-dashoffset` で書き順アニメ。署名・タイトル向け。
18. **モールス点滅から成形** — ドットが集まって文字になる(パーティクル収束)。
19. **水面浮上** — `translateY: 30→0` + 波形マスクの揺れ。水モチーフ曲。
20. **カウント風フリップ** — 空港フリップボード式に文字が回転して確定。`rotateX` を数回転。
21. **影が先に来る** — text-shadowだけ先に出現し、0.3秒後に本体。予感の演出。
22. **一文字ずつ発光** — 出現時に `text-shadow: 0 0 30px` を一瞬焚いて減衰。
23. **ノイズ砂から結晶化** — turbulence displacementを (1-p) 倍で減らす。
24. **息で曇る→文字** — 白いもや(radial-gradient)が出てから文字が浮かぶ。冬・呼気モチーフ。

## §2 強調系 (25–40) — 表示中の歌詞に感情を乗せる

25. **キーワードスケール** — 感情語だけ1.15倍+ウェイト増。1行に1語まで。
26. **キーワード色替え** — 主要語のみ Neon Rose。KNJYKKIの基本強調。
27. **ビート明滅** — 表示中、拍頭で `opacity 1→0.85→1`。
28. **揺れ(不安)** — `translateX: sin(frame*0.8)*1.5px`。細かく速い揺れ=動揺。
29. **呼吸(生)** — `scale: 1+sin(frame*0.05)*0.01`。ゆっくり=生きている。
30. **ネオン明滅故障** — ランダムに `opacity: 0.4` へ落ちて復帰。`random(seed+frame流域)`で。
31. **アンダーライン走行** — 下線が左から引かれる。決意の行に。
32. **打ち消し線** — 表示済みの行に横線→上に本音の行が出る。
33. **文字間拡張** — `letterSpacing: 0→0.3em` をゆっくり。余韻・引き伸ばされる感情。
34. **重み沈降** — 重い単語だけ徐々に `translateY: +6px`。言葉の重力。
35. **カーニング詰め** — 逆に詰めて圧迫感。焦りのパート。
36. **二重残像** — 同テキストを2px ずらし低opacityで重ねる。動揺・二心。
37. **ハイライトマーカー** — 蛍光ペン風の帯が後ろに引かれる。
38. **点滅カーソル同居** — 行末に `▍` を2Hz点滅。未完の思考。
39. **発光パルス** — ロングトーンに合わせ `text-shadow` の半径を音の長さぶん膨張。
40. **文字の視線** — 「君」等の二人称だけ、他の文字と違う色/フォントで常に表示。人格を与える。

## §3 消滅系 (41–52)

41. **フェードアウト** — 基準。出現がフェードなら消滅もフェードで対称に。
42. **ブラー霧散** — blur増加+opacity減。記憶がぼやける。§4の対。
43. **文字バラ散り** — 文字ごとに `translateY: +60px` + 回転 + ランダム遅延で落下。
44. **風に飛ぶ** — `translateX: +120px` + blur + 遅延ランダム。§22砂モチーフと接続。
45. **上昇消滅** — ゆっくり上へ。祈り・届け。
46. **吸い込まれ** — 画面のある1点(次のシーンの入口)へ全字が collapse。
47. **グリッチ消滅** — 3フレームRGB分離→ブラックアウト。強制終了感。
48. **ワイプ消し** — カラオケワイプの逆再生。言い終えた行の回収。
49. **燃え尽き** — 下から上へ `clip-path` + オレンジのエッジ発光。
50. **水没** — `translateY: +20` + 波形マスクが上から侵食。
51. **一字残し** — 全字消滅後、核心の一文字だけ2秒残す(→mv-direction §54)。
52. **消さない** — 次の行が出ても前の行を低opacityで残し、詩の連なりを見せる。バラード終盤。

## §4 レイアウト系 (53–64) — どこに置くか

53. **下部三分割定位置** — 画面下1/3の左寄せ。KNJYKKI標準ポジション。
54. **余白階層配置** — 構図の「空いた場所」に行ごとに移動。画面と対話する歌詞。
55. **中央ドン** — サビ1行目のみ中央巨大配置を解禁。平時に使わないから効く。
56. **縦書き右端** — 情緒・和のパート。行送りは右→左。
57. **対角線配置** — 不安定・疾走。回転-8°で対角に走らせる。
58. **円形パス配置** — SVG textPath で円環に。ループ・繰り返しモチーフ。
59. **画面端見切れ** — 巨大文字を意図的に見切れさせる。全部見せない強さ。
60. **吹き出し/UI配置** — チャットバブル内に歌詞(→mv-direction §17)。
61. **多言語二段組** — 日本語+英訳小文字。上下の階層でリズムを変える。
62. **歌詞の建築化** — 行を積み上げて壁・階段を作り、後のシーンで崩す。
63. **視線追従** — キャラの目線の先に歌詞を置く。歌詞=思考の可視化。
64. **奥行き配置** — 歌詞を背景と中景の「間」のz位置に置き、前景がたまに横切る。世界への埋め込み。

## §5 質感系 (65–72)

65. **グラデーション文字** — `background-clip: text` で Dawn Amber→Neon Rose。サビ用。
66. **アウトライン(袋文字)** — `-webkit-text-stroke` のみで塗りなし。Aメロの抑制。
67. **アウトライン→塗り遷移** — 感情の実体化。Bメロ→サビの橋。
68. **ノイズテクスチャ文字** — SVGパターンで粒子質感。乾いた声のパート。
69. **クロマずれ文字** — 常時0.5pxのRGB分離。デジタル世界観の常駐署名。
70. **ガラス文字** — `backdrop-filter: blur` を文字マスクで。背景を歪めて透ける。重いので1画面1行まで。
71. **金属反射** — グラデを `background-position` でスライドさせるシャイン。ここぞの決め台詞のみ。
72. **半透明重ね刷り** — mix-blend-mode: overlay で背景と干渉させる。画面に「印刷」された感。

## §6 3D・特殊系 (73–80)

73. **3D押し出し風** — text-shadowを1pxずつ8枚重ねて疑似エクストルード。
74. **パース寝かせ** — `rotateX: 55°` で地面に寝かせ、奥へスクロール(スターウォーズ式)。間奏の語りに。
75. **カメラ連動歌詞** — CameraRigの中に置き、世界と一緒に動かす(画面固定と使い分け)。
76. **ビルボード歌詞** — 世界内の看板に貼るが、常にカメラへ正対。ゲーム的。
77. **歌詞パーティクル化** — 消滅時に文字をcanvasに描き、粒子として飛散(決定論的に)。
78. **文字積層Z通過** — 行をZ軸に並べ、カメラが1行ずつ通過していく(camera-work §49)。
79. **重力演技** — 文字にバウンド着地(1回だけ、低反発)。springs.heavy。コミカル化に注意。
80. **時報同期** — 文字の出現をフレームぴったり秒針/メトロノームSEと同期。無機質な正確さ=狂気の演出。
