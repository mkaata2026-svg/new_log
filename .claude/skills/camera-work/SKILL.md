# 映画的カメラワーク 50パターン

全パターンは `remotion-foundations` の `CameraRig` 上で動く。
`cam` の各値をフレームから導出する式だけを示す。`t = frame / fps`(秒)、`p = 進行率(0→1)` とする。
進行率は `p = interpolate(frame, [start, end], [0, 1], {clamp})` で得る。

**イージングの掟**: カメラは「人が操作している」感を出すため、原則 `Easing.inOut(Easing.cubic)` か spring(knj) を使う。等速は §5の機械的演出のみ。

---

## §1 基本ムーブ (1–12)

**1. ドリーイン** — 被写体へ寄る。心理への没入、重要性の上昇。
`z: interpolate(p, [0,1], [0, 0.25])`。サビ前の4小節でじわ寄りが定石。

**2. ドリーアウト** — 引く。孤独・置き去り・全体像の提示。曲のアウトロで世界から離脱する感情。
`z: interpolate(p, [0,1], [0.3, 0])`。

**3. パン(左→右)** — 空間の紹介、時間の経過。`x: interpolate(p, [0,1], [-200, 200])`。

**4. パン(右→左)** — 逆行・回想のニュアンス。日本語話者は右→左に「戻る」を感じる。

**5. ティルトアップ** — 希望・上昇・開放。`y: interpolate(p, [0,1], [150, -150])`。サビ入りと同時が強い。

**6. ティルトダウン** — 失意・内省・着地。アウトロやブリッジで。

**7. ズームイン(光学)** — ドリーインと違いパースが変わらない=観察者的な注視。実装上は同じ `z` だがパララックス層を動かさないことで区別する。

**8. ズームアウト(光学)** — 状況の開示。「実は◯◯だった」の種明かしショット。

**9. ペデスタル(垂直移動)** — カメラ自体が昇降。ビル街を昇っていく等。`y` を大きく(±500px)、背景レイヤーに視差。

**10. トラック(平行移動)** — 被写体と並走。疾走感。`x` を等速+微ノイズ(`§4-31`)で。

**11. ロール** — 傾き回転。不安・酩酊・転調の合図。`rotate: interpolate(p, [0,1], [0, 8])`。±10°を超えると酔うので注意。

**12. 固定(ロックオフ)** — 動かさない勇気。歌詞・演技を見せたい時。前後に動くカットがあるほど固定が効く。

## §2 応用ムーブ (13–24)

**13. クラッシュズーム** — 一気に寄る。衝撃・強調。ドロップの瞬間に。
`z: interpolate(p, [0, 0.12], [0, 0.5], {clamp})` + 残り時間は保持。`Easing.out(Easing.exp)`。

**14. ホイップパン** — 高速パン+モーションブラー。カット代わりにも使う(→`transitions` §モーション系)。
`x` を8フレームで画面幅ぶん動かし `filter: blur()` を速度比例で乗せる。

**15. ヴァーティゴ(ドリーズーム)** — 寄りながらズームアウト(逆も)。背景だけが伸縮する眩暈。世界が歪む瞬間、Cメロの違和感表現に最強。
実装: 前景 `scale` 固定、背景レイヤーだけ `z` を逆方向に動かす。

**16. オービット(円弧移動)** — 被写体の周りを回る。神聖・主役感。サビの主役カットに。
`tiltY: interpolate(p, [0,1], [-15, 15])` + `x` を正弦で連動: `x: Math.sin(p * Math.PI) * 300`。

**17. クレーンアップ** — 上昇しながら俯瞰へ。フィナーレの定番。`y: -600`, `tiltX: 25` へ同時遷移。

**18. クレーンダウン** — 俯瞰から目線へ降りる。物語の始まり。イントロ1発目に。

**19. プッシュスルー** — 障害物(窓・隙間・群衆)を通り抜けて被写体へ。レイヤーを `z` 通過時に `opacity` 0へ。没入感が非常に強い。

**20. プルバックリビール** — 引いたら状況が判明する。`z` アウト + 周辺レイヤーを遅れてフェードイン。

**21. ドローンショット風** — 大俯瞰の等速移動 + 微揺れ。`tiltX: 40〜60`, `y` 等速、`§31` の呼吸ノイズ。

**22. スライダーショット** — 30〜80px の小さな横移動。「なんとなく高級」に見える最小コスト。Aメロの定番。

**23. アークイン** — 弧を描いて寄る。直線ドリーより有機的。`x: sin`, `z: linear` の合成。

**24. リフト+ロール複合** — 上昇しつつわずかに回転。浮遊感。ブリッジの無重力パートに。`y: -300`, `rotate: 4` を spring(breath) で。

## §3 主観・演技系 (25–33)

**25. POV(主観)** — 手ブレ+歩行バウンス。`y: Math.sin(t * 2π * 1.8) * 12`(歩行周期1.8Hz)+ §31ノイズ。

**26. 振り向き** — 高速 `tiltY` 90°→0°。POVで「気配に気づく」演出。

**27. のぞき見** — 画面端に前景オブジェクト(ボケた壁など)を固定し、カメラを微揺れ。盗み見の緊張感。

**28. ハンドヘルド(粗)** — ドキュメンタリー感。ノイズ振幅大きめ(±20px, ±1.5°)。感情の生々しいパートで。

**29. ハンドヘルド(密)** — 高級な手持ち。振幅±6px。「完璧すぎる画面」を防ぐKNJYKKI標準。

**30. ショルダーライド** — 被写体の背後霊ポジションで追走。`z: 0.15` 固定 + 歩行バウンス同期。

**31. 呼吸ノイズ(万能)** — すべての「生きたカメラ」の土台。
```tsx
const n = (f: number, seed: string, hz: number) =>
  Math.sin(f * hz * 0.1 + random(seed) * 100) + Math.sin(f * hz * 0.23 + random(seed + 'b') * 100);
// cam.x += n(frame,'cx',1) * amp; cam.y += n(frame,'cy',1.3) * amp * 0.7; cam.rotate += n(frame,'cr',0.7) * ampDeg;
```

**32. スナップフォーカス風** — `filter: blur(8px)→0` を6フレームで。ピントが合う=「認識した」の記号。

**33. ラックフォーカス** — 前景レイヤーと背景レイヤーの blur を交互に入れ替える。視線誘導の王道。

## §4 リズム同期系 (34–41)

**34. ビートズーム** — 拍頭で 1.05倍→1.0倍。`remotion-foundations` §3 の `pulse` をそのまま `z` に。

**35. 2拍パン往復** — 2拍で左右に振る。ダンスチューンのBメロ。`x: Math.sin(beatPhase * π) * 60`。

**36. 小節頭スナップ** — 4拍ごとに位置がカクッと切り替わる(補間8フレームのみ)。ヒップホップ系。

**37. ビルドアップ加速ズーム** — サビ前8拍で `z` を指数的に。`z: Math.pow(p, 3) * 0.4`。最後の1拍で急停止→サビ頭で解放。

**38. ドロップ静止** — ビルドアップで動きまくった後、サビ頭の1拍だけ完全静止。緩急の最終兵器。

**39. シェイク(インパクト)** — キック/クラッシュに合わせ減衰振動。
`amp = interpolate(framesSinceHit, [0, 12], [25, 0]); cam.x += n(frame,'sx',8)*amp`。

**40. 裏拍スウェイ** — 裏拍で `rotate` を±1.5°。レゲエ/R&Bの気だるさ。

**41. ハーフテンポ呼吸** — 2小節で1往復のゆっくり `z` 0↔0.08。バラードのAメロを退屈させない最小の動き。

## §5 機械・様式系 (42–50)

**42. 等速マシンパン** — 監視カメラ・SF感。あえてイージングなし。

**43. スキャンライン移動** — 一定速で縦横に走査。デジタル世界観の導入部。

**44. クアッド分割カメラ** — 画面4分割で各象限別カメラ(=別 `CameraRig`)。情報過多演出(→`mv-direction`)。

**45. 遠隔ズーム(超望遠風)** — 高倍率 `z: 0.6` + 大気の揺らぎ(blurを正弦で微変動)。距離感=切なさ。

**46. ミニチュア(チルトシフト)風** — 上下を強blur、彩度+20%。俯瞰都市を箱庭化。ノスタルジーに直結。

**47. 360ロール** — 1小節で `rotate` 360°。転調・世界の反転。1曲1回まで。

**48. マッチカット用カメラ合わせ** — 前カットの終了時 `cam` と次カットの開始時 `cam` を一致させ、被写体だけ入れ替える(→`transitions` §マッチ系)。

**49. Z軸トンネル** — 多層レイヤーを `z` 方向に等間隔配置し、カメラが `z` を等速前進、通過レイヤーは fade out。無限に進むトンネル。ビルドアップに。

**50. ゼロカメラ宣言** — 1コーラス丸ごとカメラを完全固定し、ラスサビで初めて動かす。「動き」は使わなかった時間の長さだけ強くなる。構成レベルの最強パターン。
