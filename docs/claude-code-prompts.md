# Claude Code への指示テンプレート集

KNJYKKI MV制作でClaude Codeに出す指示の定型文。`<>` を埋めてそのまま貼る。
テンプレートを使うとスキルの自動読み込みが正しく発火し、成果物の粒度が安定する。

---

## T1. 新規MV立ち上げ(企画から)

```
新しいMVを作ります。企画から始めてください。

曲名: <曲名>
slug: <英小文字-ハイフン>
長さ: <3:34 など> / BPM: <128> / 拍子: <4/4>
構成: <intro 0:00 / Aメロ 0:15 / Bメロ 0:45 / サビ 1:00 / ... (分かる範囲で)>
曲の感情・テーマ: <失恋 / 夜の疾走 / 再会 など自由記述>
歌詞: <全文 or ファイルパス。タイムスタンプがあれば添付>
参考にしたい雰囲気: <あれば>

やってほしいこと:
1. mv-direction / emotional-psychology / docs/brand-knjykki.md を参照して
   感情曲線と絵コンテ表(セクション×演出パターン番号)を提案
2. 主モチーフ1つ+従モチーフ2つを提案(mv-direction §2から)
3. 色のアーク設計(color-design §3準拠)
4. scene-library から再利用するコンポーネントのリストアップ
まだ実装はしないでください。絵コンテ表への合意が先です。
```

## T2. 絵コンテ承認→実装開始

```
絵コンテを承認します(修正点: <あれば>)。
src/videos/<slug>/ を作成し、song.ts(セクション・歌詞タイムスタンプ)→
SectionSequencer骨格 → 各シーンの順で実装してください。
CLAUDE.mdの規約とremotion-foundationsのテンプレートに従うこと。
まずイントロ〜1サビまで実装して確認させてください。
```

## T3. 個別シーンの実装・修正

```
<slug> の <セクション名> を実装(修正)してください。
使う演出: <mv-direction #__ / camera-work #__ / lyrics-animation #__>
雰囲気: <自由記述>
制約: <尺、使う色、NG事項>
```

## T4. サビの強化

```
<slug> の <1番/2番/ラス>サビが弱いです。chorus-impact を参照して強化してください。
- 現状の不満: <盛り上がらない / Aメロと差がない / 点火が弱い など>
- chorus-impactのサビ設計テンプレートを埋めて提案→合意後に実装
- 1番<2番<ラスサビの単調増加が崩れていないかも確認してください
```

## T5. 歌詞アニメーションの指定

```
<slug> の歌詞表示を作り込んでください。lyrics-animation を参照。
- セクションごとの指定: <Aメロ=#2ライズ / サビ=#13拡大衝突+#65グラデ など。
  番号でなく雰囲気指定でも可: 「Aメロは記憶がにじむ感じ」>
- 1本のMVで出現系3種まで、の掟を守ること
- タイムスタンプは song.ts の lyrics に入っています(なければ概算で置いて後で調整)
```

## T6. トランジション調整

```
<slug> の <どこ→どこ> のつなぎを変えてください。transitions を参照。
意味: <場所の移動 / 時間経過 / 回想へ / 章の転換>
今のつなぎの不満: <唐突 / ダサい / 尺が合わない>
ビート量子化(0.5拍/1拍/2拍)を守ってください。
```

## T7. カラーグレーディング

```
<slug> の色を調整してください。color-design を参照。
- 全体の不満: <彩度が平坦 / サビが点灯しない / 夜が濁る>
- 色のアークを見直し、セクションごとのGradeパラメータ表を出してから実装
- knj-theme.ts 経由・HEX直書き禁止を確認
```

## T8. レビュー依頼

```
<slug> をレビューしてください。
CLAUDE.mdのレビューチェックリスト+emotional-psychology §9(企画レビュー)を実行し、
問題点を重要度順に列挙。修正はまだしないでください。
```

## T9. ライブラリ昇格(MV完成時に必ず実行)

```
<slug> が完成しました。蓄積フェーズをお願いします。
1. このMVで新規実装した演出のうち汎用性のあるものを scene-library/ へ昇格
   (scene-library/README.md の昇格手順に従う)
2. registry.md に登録行を追加
3. docs/mv-log/<slug>.md に制作ログを作成
   (使用パターン番号一覧 / うまくいった点 / 次回への学び)
```

## T10. レンダリング

```
<slug> を書き出してください。
- 全編: npx remotion render <slug> out/<slug>.mp4
- 確認用にサビだけ / サムネ静止画も (remotion-foundations §10)
レンダ前に警告ゼロを確認してください。
```

## T11. 部分プレビューでの往復(作業中の定型)

```
<slug> の <時間帯 0:58-1:10> だけ見たい。フレーム指定でレンダして。
気になる点: <歌詞が読めない / カメラが速い など>
```

## T12. 既存MVからの流用

```
<過去slug> でやった <演出の説明 or registry名> を <新slug> の <セクション> に流用してください。
そのままではなく <変更点> だけ変えて。
※ もしその演出がまだ scene-library に昇格されていなければ、先に昇格してから使うこと。
```

---

## 指示のコツ

- **番号で話す**: 「いい感じのトランジション」より「transitions #101」。番号はスキル辞典と直結する。
- **雰囲気語も歓迎**: 番号が分からなければ感情語で書けば、Claudeがスキルから候補を出す。
- **1指示1関心事**: 色とカメラと歌詞を1つの指示に混ぜない。T3〜T7を分けて出す。
- **T9を飛ばさない**: ライブラリ蓄積こそがこのシステムの複利。完成の定義に含まれている。
