各ログの型:

```markdown
# <曲名> (<slug>) — YYYY-MM-DD

## 使用パターン
- mv-direction: #__, #__ / camera-work: #__ / lyrics-animation: #__
- chorus-impact: #__ / transitions: #__

## scene-library 昇格
- Knj〇〇 (新規) / Knj〇〇 (再利用)

## うまくいった点 / 次回への学び
- ...
```
