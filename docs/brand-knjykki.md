## 1. 世界観ステートメント

**「終わりかけの夜が、一番きれい。」**

KNJYKKIの映像は、深夜2時から夜明けまでの時間に住んでいる。
都市の光はもう半分眠っていて、ネオンは疲れて明滅し、始発はまだ来ない。
デジタルの冷たさと、記憶のぬくもりが同じ画面に同居する。
完璧ではないもの — ノイズ、手ブレ、消えかけの看板 — にだけ宿る「生きている」感じを、最新の技術で丁寧に作る。

### 世界観キーワード(企画時の羅針盤)
夜明け前 / 都市の孤独 / ネオンの残光 / 車窓 / 電波とノイズ / 未送信のメッセージ / 郷愁とデジタルの同居 / 半端な時間(2:47amのような) / 「ひとりだけど、ひとりじゃない」

### KNJYKKIが「やらないこと」
- 昼の快晴・パーティー的多幸感をそのまま描く(光は必ず闇の中に置く)
- 説明しすぎる(顔・結末・意味を全部見せない)
- 完璧に整った画面(ノイズゼロ・グレインゼロは無人の画面)
- 流行演出の直輸入(必ずKNJYKKIの色とモーション署名に翻訳して使う)

## 2. カラー

`scene-library/lib/knj-theme.ts` が唯一の正。HEX直書き禁止。

| 名前 | HEX | 意味 |
|---|---|---|
| Midnight | #0B0E1A | 世界の地色。夜そのもの |
| Midnight 2 | #141A2E | 夜の中の階調 |
| Neon Rose | #FF4D6D | 感情・心拍・サビ。KNJYKKIの「体温」 |
| Cyan Ash | #4CC9F0 | モニター光・冷静・孤独 |
| Dawn Amber | #FFB86B | 記憶・希望・夜明け。**終盤まで温存する色** |
| Ghost White | #F5F3F0 | 言葉と光。純白ではない生成り |

運用ルールは `color-design` スキル §4。基本アークは「夜明け型」(同 §3)。

## 3. タイポグラフィ

- **日本語(歌詞主役)**: 明朝系(例: 源ノ明朝/しっぽり明朝系)。感情の細さ・繊細さを担う。サビでウェイトを上げる(lyrics-animation §50)。
- **欧文(補助・装飾)**: コンデンスド・サンセリフ(例: Oswald / Barlow Condensed 系)。都市のサイン・データ感を担う。
- **手書き**: 1作品1箇所まで。最も感情的な1行に(emotional-psychology §6)。
- 級数の目安(1080p): 歌詞標準 44-56px / サビ中央解禁時 96-160px / 注釈・英訳 20-24px。
- 字間: 明朝の歌詞は `letter-spacing: 0.06em` 基準。詰まった明朝はKNJYKKIではない。

## 4. モーション署名

- 立ち上がり重く、減衰長く。`springs.knj (damping: 200)` が標準。
- カメラは常に微かに呼吸している(camera-work §29/§31)。完全静止は演出としての静止のみ。
- 点滅・明滅はネオンの物理(2回瞬いてから点く、たまに落ちる)に従う。
- コミカルなバウンス・伸び縮み(squash & stretch)は禁止。KNJYKKIの物体は重い。

## 5. 質感署名

- 全カットに グレイン(opacity 0.04-0.08)+ビネット(0.35-0.5)。
- 光には必ずブルーム(にじみ)。シャープな光はデジタル過ぎる。
- 画面のどこかに常に1つ「不完全」を置く: 明滅するネオン / 走るノイズ1本 / 揺れるカーテン。

## 6. ロゴ・アイデンティティ表示

- 表記は `KNJYKKI`(全大文字・欧文コンデンスド)。
- 定位置: MV冒頭または末尾の右下、Ghost White、opacity 0.85。
- タイトルドロップ(曲名表示)は1番サビ頭 または 冒頭0.5秒フラッシュ(mv-direction §4)。
- 全MV共通の署名演出: **ラスト「10秒の余韻」**(mv-direction §100)+ ロゴの静かなフェードイン。

## 7. 音と映像の関係(ブランドとしての編集律)

- カットと演出はビート量子化(transitions 冒頭)。ズレは「演出としてのズレ」のみ許可。
- サビは差分で作る(chorus-impact 大原則)。1番<2番<ラスサビの単調増加。
- 曲が終わっても映像はすぐ終わらない。余韻はKNJYKKIの署名。

## 8. 判断フローチャート(迷ったら)

```
その演出はKNJYKKIか?
├─ 光が闇の中にあるか? ──── No → 闇を足すか、演出を変える
├─ 不完全さが残っているか? ─ No → グレイン/明滅/手ブレを足す
├─ 色はパレット内か? ─────── No → knj-theme.ts に翻訳する
├─ 動きは「重く粘る」か? ─── No → springs.knj に寄せる
└─ 全部Yes → 採用。scene-libraryへの昇格も検討
```
